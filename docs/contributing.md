# Contributing

VLatte is developed on [GitHub](https://github.com/caffeine-projects/vlatte). Bug reports, ideas and pull requests are welcome.

## Pull requests

Read [CONTRIBUTING.md](https://github.com/caffeine-projects/vlatte/blob/main/CONTRIBUTING.md) before you open one. It covers setup, the checks CI runs, the conventions reviewers look for, and the commit format.

## Issues

Open an issue with one of the [issue forms](https://github.com/caffeine-projects/vlatte/issues/new/choose):

- **Bug report:** include the VLatte version, what you expected, what happened, and the smallest mock or test that reproduces it.
- **Feature request:** describe the problem it solves before the API you have in mind.
- **Other:** documentation issues and usage questions.

Search the [existing issues](https://github.com/caffeine-projects/vlatte/issues) first.

## Security

Do not report a vulnerability in a public issue. Report it privately through [GitHub security advisories](https://github.com/caffeine-projects/vlatte/security/advisories/new), as the [security policy](https://github.com/caffeine-projects/vlatte/blob/main/SECURITY.md) explains. Only the latest release gets security fixes.
