## Stable addresses

These files are served as they are, for editors, generators and mock files to point at:

| What | Address |
|---|---|
| HTTP mock file schema | `https://vlatte.dev/schemas/http.schema.json` |
| gRPC mock file schema | `https://vlatte.dev/schemas/grpc.schema.json` |
| Admin API OpenAPI document | `https://vlatte.dev/openapi/admin.yaml` |

They follow the `main` branch of the repository.
